# ChaosChunks Server Use

## First World Creation

Create this file before the first dedicated server start:

`config/chaoschunks-server-worldgen.json`

Example:

```json
{
  "enableOnFirstWorldCreation": true,
  "regionX": 4,
  "regionZ": 4,
  "globalBiomes": "",
  "defaultDimensionMode": "SAFE",
  "regionSeedMode": "RANDOMIZED_REGION_SEED",
  "terrainProfileMode": "NORMAL",
  "dimensionModes": {
    "minecraft:overworld": "ON",
    "minecraft:the_nether": "SAFE",
    "minecraft:the_end": "SAFE"
  },
  "dimensionBiomes": {},
  "dimensionSeedRandomizers": {},
  "dimensionTerrainRandomizers": {}
}
```

On first world startup, ChaosChunks applies this file only if the world has no saved ChaosChunks settings yet. After that, saved world data wins.

## JSON Fields

- `enableOnFirstWorldCreation`: set `true` to seed a new world from this file.
- `regionX` / `regionZ`: region size in chunks, clamped to `1..512`.
- `globalBiomes`: global biome filter text. Blank means mode default.
- `defaultDimensionMode`: `ON`, `SAFE`, or `OFF` for dimensions not listed in `dimensionModes`.
- `regionSeedMode`: `WORLD_SEED` or `RANDOMIZED_REGION_SEED` for dimensions without explicit seed randomizers.
- `terrainProfileMode`: `NORMAL` or `RANDOMIZED_TERRAIN_PROFILES` for dimensions without explicit terrain randomizers.
- `dimensionModes`: per-dimension mode overrides.
- `dimensionBiomes`: per-dimension biome filter overrides.
- `dimensionSeedRandomizers`: per-dimension long seed salts. Omit a dimension to use world seed.
- `dimensionTerrainRandomizers`: per-dimension long salts for randomized terrain profiles. Omit a dimension to use `terrainProfileMode`.

## JVM And Environment Overrides

These override the JSON while the server is running:

```bash
java -Dchaoschunks.enabled=true \
     -Dchaoschunks.regionX=4 \
     -Dchaoschunks.regionZ=4 \
     -Dchaoschunks.defaultDimensionMode=SAFE \
     -Dchaoschunks.regionSeedMode=RANDOMIZED_REGION_SEED \
     -Dchaoschunks.terrainProfileMode=RANDOMIZED_TERRAIN_PROFILES \
     -jar neoforge-server.jar nogui
```

Container-friendly environment variables:

```bash
CHAOSCHUNKS_ENABLED=true
CHAOSCHUNKS_REGION_X=4
CHAOSCHUNKS_REGION_Z=4
CHAOSCHUNKS_DEFAULT_DIMENSION_MODE=SAFE
CHAOSCHUNKS_REGION_SEED_MODE=RANDOMIZED_REGION_SEED
CHAOSCHUNKS_TERRAIN_PROFILE_MODE=RANDOMIZED_TERRAIN_PROFILES
```

## Commands

Requires gamemaster permission.

```mcfunction
/chaoschunks status
/chaoschunks reload
/chaoschunks save
/chaoschunks export config/chaoschunks-export.json
/chaoschunks import config/chaoschunks-export.json
/chaoschunks set enabled true
/chaoschunks set region 4 4
/chaoschunks dimension minecraft:overworld mode ON
/chaoschunks dimension minecraft:the_nether mode SAFE
/chaoschunks dimension minecraft:the_end mode OFF
/chaoschunks dimension minecraft:overworld seed randomized
/chaoschunks dimension minecraft:overworld seed world
/chaoschunks dimension minecraft:overworld terrain randomized
/chaoschunks dimension minecraft:overworld terrain normal
```

## Notes

- Use `reload` after editing `config/chaoschunks-server-worldgen.json`.
- Use `import` when you want to apply a JSON file directly to an already-created world.
- Use `save` to write the active world's ChaosChunks settings back to `config/chaoschunks-server-worldgen.json`.
- Use `export` to make a separate reusable preset file.
- Existing generated chunks are not regenerated by changing these settings.
- None of these features have fully been tested. Please report any bugs to the source code github page.
